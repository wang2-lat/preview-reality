# preview-reality

CLI tool to generate realistic product previews and reduce custom order returns

## Problem

Custom product sellers face 12-15% return rates because customers say "it doesn't match the picture". This tool helps set realistic expectations by simulating actual material effects, color differences, and detail limitations.

## Features

- **Material Simulation**: Simulate canvas, paper, or fabric texture effects
- **Color Calibration**: Generate screen vs print color comparison
- **Detail Annotation**: Automatically mark areas that may lose detail in production
